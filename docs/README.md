# docs/

Project artifacts — what this actual project/system **is** — as opposed
to `.agent/skills/`, which is how an agent **performs** a task.

Populated at Tier M and above (see the ceremony tier table in
`AGENTS.md`). Tier XS/S work does not create anything here.

```
product/        PRD.md                    — Tier L only
technical/      TRD.md                    — Tier L only
architecture/   system/frontend/backend/database/api.md, decisions/*.md — Tier L
tasks/          BOARD.md + TASK-00X-*.md  — Tier M and L
CONVENTIONS.md  generated by the recon skill on an existing codebase
```

PRD/TRD/ADR templates ship in v0.2 (see the roadmap in
`VibeDiscipline-Full-Plan.md`, Section 45) — v0.1 covers Tier M work via
the task doc template in `.agent/skills/planning/SKILL.md`.
