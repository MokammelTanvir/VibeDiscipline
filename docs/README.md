# docs/

Project artifacts — what this actual project/system **is** — as opposed
to `.agent/skills/`, which is how an agent **performs** a task.

Populated at Tier M and above (see the ceremony tier table in
`AGENTS.md`). Tier XS/S work does not create anything here.

```
product/        PRD.md                    — Tier L only
technical/      TRD.md                    — Tier L only
architecture/   system/frontend/backend/database/api.md, decisions/*.md — Tier L
tasks/          BOARD.md + TASK-00X-*.md  — Tier M and L
CONVENTIONS.md  generated by the recon skill on an existing codebase
index.html      the landing page (served by GitHub Pages from this folder)
GUIDE.md        how to install, use, configure, upgrade and remove VibeDiscipline
ROADMAP.md      status, what ships when, known limitations
PERMISSIONS.md  generated from .agent/permissions.yml
```

Under `waterfall` the PRD and TRD are phase gates: each needs `approved_by`
and `approved_at` before implementation (see
`.agent/skills/_shared/methodology.md`).

PRD, TRD and ADR templates are in `.agent/skills/planning/templates/`;
the task doc template is in `.agent/skills/planning/SKILL.md`.
